# 文本对比功能

## 功能概述

新增了优化前后文本对比功能，让用户可以清晰地看到文本优化的效果。

---

## 功能特性

### 1. 视觉对比
- **优化前文本**：灰色背景区域，标有红色圆点标识
- **优化后文本**：蓝色背景区域，标有绿色圆点标识
- **分隔箭头**：向下箭头清晰标示优化方向

### 2. 用户体验
- **即时反馈**：点击优化按钮后立即显示原始文本
- **流式显示**：优化后的文本逐字显示，实时更新
- **加载状态**：优化进行时显示旋转加载图标
- **滚动支持**：长文本自动添加滚动条

### 3. Apple 设计规范
- ✅ 毛玻璃效果（backdrop-blur）
- ✅ 圆角设计（rounded-xl）
- ✅ 半透明背景
- ✅ 优雅的动画（slideIn）
- ✅ 语义化颜色（红色=原始，绿色=优化）

## 技术实现

### 新增组件

#### TextComparison.tsx
```tsx
interface TextComparisonProps {
  originalText: string;
  optimizedText: string;
}
```

**功能**：
- 显示优化前后文本对比
- 支持长文本滚动（最高 96px）
- 空文本时显示加载状态
- 使用语义化颜色区分

**设计细节**：
- 圆点标识：红色（优化前）、绿色（优化后）
- 标签文字：灰色小号字体
- 背景色：优化前为灰色，优化后为蓝色
- 边框：50% 不透明度，增加层次感

### 更新的组件

#### useTextOptimization Hook
**新增状态**：
```tsx
const [originalText, setOriginalText] = useState('');
```

**返回值新增**：
```tsx
return {
  // ...
  originalText, // 新增
  // ...
}
```

#### ContentApp.tsx
**替换**：
- `OptimizedTextPreview` → `TextComparison`

**新增 props**：
```tsx
<TextComparison
  originalText={originalText}
  optimizedText={optimizedText}
/>
```

## 用户流程

### 1. 初始状态
用户点击优化按钮

### 2. 优化中
```
优化前: 显示原始文本
   ↓
优化后: 显示加载图标 + "正在优化文本..."
```

### 3. 优化完成
```
优化前: 显示原始文本
   ↓
优化后: 逐字显示优化结果
```

### 4. 准备替换
用户可以查看对比，决定是否替换

### 5. 替换或取消
- 点击绿色按钮：替换原文本
- 点击关闭按钮：取消替换

## 样式规范

### 颜色系统

#### 优化前区域
```css
background: gray-100/80 (浅色) | gray-800/60 (深色)
text: gray-600 (浅色) | gray-400 (深色)
border: gray-200/50 (浅色) | gray-700/50 (深色)
indicator: red-400 (浅色) | red-500 (深色)
```

#### 优化后区域
```css
background: blue-50/80 (浅色) | blue-900/20 (深色)
text: gray-800 (浅色) | gray-200 (深色)
border: blue-200/50 (浅色) | blue-800/50 (深色)
indicator: green-400 (浅色) | green-500 (深色)
```

#### 箭头分隔
```css
color: blue-500 (浅色) | blue-400 (深色)
```

### 间距系统
- 容器间距：`space-y-2` (8px)
- 标签间距：`space-y-1.5` (6px)
- 内边距：`px-4 py-2.5` (16px, 10px)
- 标签 padding：`px-1` (4px)

### 尺寸限制
- 最大宽度：`max-w-2xl` (672px)
- 最大高度：`max-h-24` (96px，约 6 行文本)
- 溢出处理：`overflow-y-auto`
